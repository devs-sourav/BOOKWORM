# 📧 Email Configuration Guide for BookWorm on Render

## ✅ Complete Setup Instructions

### Step 1: Generate Gmail App Password
1. Go to [Google Account Security](https://myaccount.google.com/security)
2. Enable **2-Step Verification** (if not already enabled)
3. Create an **App Password**:
   - Select "Mail" as the app
   - Select "Windows Computer" (or your device)
   - Click "Generate"
   - Copy the 16-character password

### Step 2: Set Environment Variables on Render

Go to your Render service → Settings → Environment Variables and add:

```
EMAIL_SERVICE=gmail
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=xxxx xxxx xxxx xxxx
EMAIL_FROM=BookWorm <your-email@gmail.com>
FRONTEND_BASE_URL=https://your-frontend-domain.com
```

**Important Notes:**
- Use the **App Password** (not your regular Gmail password)
- Include spaces in the 16-character password as generated by Google
- `FRONTEND_BASE_URL` must be your actual frontend domain (e.g., https://bookworm.com)

### Step 3: Verify Configuration

After deployment, check Render logs for:
- ✅ "Email service verified successfully"
- ✅ "Email sent successfully"

### Step 4: Test Registration

1. Go to your frontend signup page
2. Register with a test email
3. Check your email inbox for the verification link
4. Verify the email address

## 🔧 Troubleshooting

### Email Not Sending?

**Check 1: Environment Variables**
- Verify all variables are set in Render dashboard
- Ensure `EMAIL_PASSWORD` is the App Password, not your Gmail password
- Ensure `FRONTEND_BASE_URL` is correct (with https://)

**Check 2: Gmail Account**
- Verify you have enabled 2-Factor Authentication
- Check that the app password was generated correctly
- Try generating a new app password if needed

**Check 3: Gmail Less Secure Apps**
- If using regular Gmail password (not recommended):
  - Go to [Google Account Settings](https://myaccount.google.com/security)
  - Disable "2-Step Verification"
  - Enable "Less secure app access"
  - BUT: **Use App Password instead - it's more secure!**

**Check 4: Render Logs**
- Go to your Render service → Logs
- Look for "EMAIL SEND ERROR" messages
- Check the detailed error message

### Common Errors

| Error | Solution |
|-------|----------|
| `Invalid login: 535-5.7.8 Username and password not accepted` | Use App Password, not Gmail password |
| `Cannot find module 'nodemailer'` | Run `npm install` in server folder |
| `FRONTEND_BASE_URL is undefined` | Set the environment variable in Render |
| `connect ECONNREFUSED 127.0.0.1:587` | Check environment variables and email config |

## 📝 Alternative Email Services

### Using SendGrid
```env
EMAIL_SERVICE=sendgrid
EMAIL_USERNAME=apikey
EMAIL_PASSWORD=sg_xxxxxxxxxxxxxxxxxxx
EMAIL_FROM=BookWorm <noreply@bookworm.com>
```

### Using Mailgun
```env
EMAIL_HOST=smtp.mailgun.org
EMAIL_PORT=587
EMAIL_SECURE=false
EMAIL_USERNAME=postmaster@mg.bookworm.com
EMAIL_PASSWORD=your-mailgun-password
EMAIL_FROM=BookWorm <noreply@bookworm.com>
```
